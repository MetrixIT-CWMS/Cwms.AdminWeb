# CWMS AdminWeb - Admin Web Application
Company Websites Management System - Admin Web Application

## Getting started

Clone an existing Git repository with the following command:

1. cd ../workspace/CWMS/
2. Clone the repo using following git command: `git clone https://github.com/MetrixIT-Solutions/Cwms.AdminWeb.git`
3. Go to the appropriate directory to start the App: `cd Cwms.AdminWeb`
4. node version >=22.17.0
5. Run `yarn` or `npm install -f` to install dependencies
6. Run the command: `npm run start`
7. You can find the application working status in browser url `http://localhost:4212`

Push an existing Git repository with the following command:

```
cd existing_repo
git remote add origin https://github.com/MetrixIT-Solutions/Cwms.AdminWeb.git
git branch -M main
git push -uf origin main
```
